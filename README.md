# Klyro Standalone v2

A standalone local Klyro commerce app with separate customer and business experiences.

## Customer flow
Business cards only on Home -> category filter -> search intent such as "I need cake" -> nearby matching businesses -> business menu -> item photo/details -> order form -> Place order -> 30-minute delivery countdown.

## Business flow
Use provider@klyro.local / Provider@12345. Business dashboard shows menu, active/total orders, order status controls, and real item-photo upload from the phone gallery.

## Customer demo
user@klyro.local / User@12345

## Run
Node.js 18+

npm install
npm start

Open http://localhost:3000
